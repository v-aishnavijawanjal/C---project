# HOME DESIGN SELECTOR

A simple C program that allows users to select their preferred wall color, flooring, and kitchen type. After selecting the options, the program displays a complete home design summary.

## Technologies Used
- C Programming
- Conditional Statements
- User Input/Output

## Features
- Customer name input
- Wall color selection
- Flooring selection
- Kitchen selection
- Final design summary
